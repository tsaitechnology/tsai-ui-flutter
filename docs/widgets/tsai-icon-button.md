# TsaiIconButton

`TsaiIconButton` provides a 40-pixel icon action with an optional composed
`TsaiBadgeDot` or `TsaiBadgeCounter` overlay.

```dart
TsaiIconButton(
  icon: const Icon(Icons.notifications_none),
  badge: const TsaiIconButtonBadgeCount(3),
  onPressed: () {},
)
```
