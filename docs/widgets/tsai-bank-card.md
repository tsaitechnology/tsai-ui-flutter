# TsaiBankCard

A 342×214 payment-card face. The graphite gradient, indigo glows, hairline, and
soft shadow stay dark in both themes. Wordmark, contactless glyph, number, and
network mark are independently optional.

[Open live example](https://tsaitechnology.github.io/tsai-ui-flutter/example/#/bank-card){ target="_blank" rel="noopener" .md-button }

```dart
const TsaiBankCard(
  wordmark: 'tsaitech',
  number: '•••• 4821',
  network: 'VISA',
)
```

Corner radius uses the `radius.card` token (20).
