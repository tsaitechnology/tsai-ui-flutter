# TsaiPageIndicator

A row of page dots with one active 24×8 pill. Inactive dots are 8×8. The row
uses `spacing.8` and `color.accent.light` / `color.border.hairline`.

[Open live example](https://tsaitechnology.github.io/tsai-ui-flutter/example/#/page-indicator){ target="_blank" rel="noopener" .md-button }

```dart
TsaiPageIndicator(count: 5, index: 2)
```
